# Pulse server

1. Install Node.js, then in this folder run:  npm install
2. Start it:  npm start
3. Open http://localhost:3000   (any valid email + 8+ character password)

Files: server.js (routes), scoring.js (health score engine), data.js (sample data), public/ (the website).
API: POST /api/login, GET /api/projects, GET /api/projects/:id, GET /api/alerts, GET/PUT /api/settings
